# AttSchool Africa Assignment

This repository contains my web development assignment for AttSchool Africa, showcasing HTML skills through two pages: an "About Me" page with multimedia elements and a courses page listing AttSchool Africa's offerings.

## Project Overview

The assignment demonstrates the use of HTML to create structured web pages with embedded media and tabular data. It includes:
- **`media.html`**: An "About Me" page featuring responsive images, a video introduction, an audio message, a PDF work sample, and an embedded Google Map.
- **`table.html`**: A page displaying a table of courses offered by AttSchool Africa's Schools of Engineering, Product, and Data.
- **Assets**: Media files used in `media.html`, including images, video, audio, and a PDF.

### File Descriptions
- **media.html**:
  - Displays a personal introduction with:
    - A responsive `<picture>` element for profile images (`large-me.jpg`, `medium-me.jpg`, `small-me.jpg`, `me.jpg`).
    - A `<video>` element for an introduction video (`chris.mp4`).
    - An `<audio>` element for a personal message (`chris.mp3`).
    - An `<embed>` element for a work sample PDF (`sample-work.pdf`).
    - An `<iframe>` embedding a Google Map.
- **table.html**:
  - Presents a table listing courses offered by AttSchool Africa, organized by school (Engineering, Product, Data) with nested unordered lists for course details.
- **Media Files**:
  - Images, video, audio, and PDF files referenced in `media.html` to enhance the page's interactivity and visual appeal.
